## Why No Third-Party Speaker Model Was Used

Reliable free model sources were checked first, including Sketchfab, CGTrader, OpenGameArt, GitHub, Kenney, Blend Swap, and Poly Haven.

Findings:

- Sketchfab had relevant PA/stage speaker models under commercial-friendly licenses such as CC BY, but its download API requires authenticated account access. This was not bypassed.
- CGTrader had free PA speaker listings, but download generally requires a free account/login. This was not bypassed.
- GitHub public repository search did not return a suitable professional PA speaker GLB/GLTF model with clear commercial licensing.
- OpenGameArt, Kenney, Blend Swap, and Poly Haven did not provide a suitable professional PA stage speaker assembly model matching the required exploded-view use case.

Because no anonymous, directly downloadable, clearly commercial-use professional PA speaker model was found, the final implementation uses a self-built model instead.
